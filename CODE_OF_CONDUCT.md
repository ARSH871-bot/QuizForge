# Code of Conduct

## The standard

Be straightforward and be kind. Disagree with the work, not the person.
Assume the other party is competent and acting in good faith until you have
concrete reason to think otherwise.

Specifically, in issues, pull requests and discussions:

- Critique the code, the design or the decision — never the author
- Say what you actually think, including when it is unwelcome. Withheld
  disagreement is worse than blunt disagreement
- Bring evidence. "This is wrong" is not review; "this fails when X because Y"
  is
- Accept that being shown wrong is a good outcome, not a loss

Unacceptable: harassment, personal attacks, discriminatory language, sustained
disruption, or publishing others' private information.

## Scope

Applies in every project space — issues, pull requests, discussions, commit
messages, and any private correspondence conducted on the project's behalf.

## Enforcement

Raise concerns with the maintainer directly. While the repository is private,
everyone who can read this file already has a way to do that, and GitHub's
private advisory channel is unavailable on the Free plan (ADR 0013) — so it is
not offered here. A published channel that does not work is worse than none.

Reports are read by the maintainer. Consequences range from a request to
change behaviour to a permanent ban, in proportion to the conduct.

While this is a solo project, that process is short. It is written down now
because writing it down after it is needed is too late.
