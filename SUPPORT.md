# Support

## Where to go

| What you have | Where it goes |
|---|---|
| A bug — behaviour differs from what is documented | [Open an issue](https://github.com/ARSH871-bot/QuizForge/issues/new/choose) |
| A feature idea | [Open an issue](https://github.com/ARSH871-bot/QuizForge/issues/new/choose) |
| A question, or an idea not yet formed enough to be a proposal | [Discussions](https://github.com/ARSH871-bot/QuizForge/discussions) |
| A security vulnerability | [SECURITY.md](SECURITY.md) — never a public issue |

## Before opening an issue

Read [STATUS.md](STATUS.md). It records what is complete, what is deliberately
not built yet, and every known gap. A good number of surprises are already
documented there — in particular, this is pre-launch software and is **not
safe to deploy anywhere reachable** for the reasons that file lists.

## What to expect

This is a solo, pre-launch project. Response times are best-effort rather than
contractual — expect acknowledgement within a week. There is no support
contract and no SLA.

## Getting it running

[README.md](README.md) gets you from clone to a running API. Every command in
it is executed and verified before release; if one does not work, that is a
bug worth reporting.
